Overview of the N-Puzzle

Objective

The N-Puzzle is a square-shaped sliding block puzzle where the goal is to arrange N blocks numbered from 1 to N in numeric order from left to right, top to bottom. A random starting state for the 8-puzzle, as well as its solution state, is shown below.

A random 8-puzzle start state.
The solved state for the 8-puzzle

The N in N-Puzzle is a positive integer that equals one less than the square of a positive integer (so that N = i2 - 1, where i is some positive integer), so for example N could equal 3, 8, 15 or 24 (which means i equals 2, 3, 4 or 5 respectively). N represents the number of blocks in the puzzle grid, which is a square bounded grid with one 'empty space'. One block adjacent to the empty space (meaning a block immediately to the left, right, top or bottom of the empty space) can be moved one space at a time. Blocks can not be moved diagonally.
